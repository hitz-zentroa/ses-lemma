# ses-lemma
This collection of files contains datasets for 7 languages (Russian, Basque, Turkish, Spanish, Czech, English, and Polish) corresponding to 3 different SES formats, namely, ses-udpipe, ses-ixapipes and ses-morpheus. These files are ready to use and are suitable to fine-tune such models as XLM-RoBERTa-large in a token classification task in to perform lemmatization.
